# そこそこ！孫の手急便

夜の商店街で、閉店間際の「孫の手急便」に３人のお客さんが駆け込んできます。「もうすこし 右」を手がかりに、孫の手を肩ひもやフードのすき間へ。「そこそこ！」の場所で小さく２往復して、お客さんの背中をすっきりさせるブラウザゲームです。

**制作者**　果糖

**ハッカソンのテーマ**　かゆいところに手が届くようなアプリ

「あと少しなのに、手が届かない」という困りごとから、相手の反応を見て、届く道を探す遊びを作りました。

- [ブラウザで遊ぶ](https://takkaspringer.github.io/sokosoko-magonote/)
- [ソースコード](https://github.com/takkaspringer/sokosoko-magonote)

## あそびかた

1. マウスや指で、画面内の丸い入口を押したまま動かします。
2. 吹き出しを頼りにかゆい場所を探します。コツッと当たったら壁に沿って回り込むか、「手を ひく」で別の入口へ。指を離しても孫の手は止まった場所からつかみ直せます。
3. 「そこそこ！」が出たら、横に小さく動かして元の位置へ。２往復で１か所クリアです。

| 面 | お客さん | 仕掛け | 制限 | ★2 |
| --- | --- | --- | ---: | ---: |
| 1 | 配達員のゴンさん | 肩ひもの端を回るか、浮いたすき間から近道 | 50秒 | 30秒 |
| 2 | ミオちゃん | 左・右・えり元。布に沿って次の場所へ | 60秒 | 38秒 |
| 3 | タヌキ店長 | しっぽが空ける側を読んで近道 | 65秒 | 42秒 |

全箇所クリアで★1、目標タイム以内なら★2、そのうえ全箇所で最初の「そこそこ！」から範囲を外れず２往復すれば★3です。探索中にぶつかっても評価に影響しません。タイム・星・スコアは各面で個別に端末へ保存されます。

Escでポーズできます。タブやアプリを離れると自動で止まります。設定では音量、ヒント、時間制限、ゆれ、文字サイズを変更できます。時間制限の変更は次の面かリトライ時に適用します。

## ローカル起動とビルド

Node.js 22 以降を使用します。

```text
npm ci
npm run dev
npm run build
npm run preview
```

開発とプレビューのURLはターミナルに表示されます。`dist/` が静的配信用の成果物です。相対パスでビルドしているため、リポジトリ配下でも動きます。GitHub Pagesでは公開元に GitHub Actions を選び、［Deploy GitHub Pages］を実行します。

ステージの座標、時間、セリフ、障害物の動きは `src/stages.ts` で調整できます。Canvasと衝突判定が同じ障害物データを使用しています。

## 素材・クレジット

- 作品・制作クレジット　果糖
- 店先、看板、のれん、キャラクター、衣服、孫の手は本作のオリジナルCanvas描画。
- 木琴風のBGMと効果音は本作用にWeb Audioで作成。外部音源や音声ファイルは使用していません。
- 書体は端末にある丸ゴシック・ゴシック体を使用。フォントファイルの同梱や外部取得はありません。
- Vite、TypeScriptと各開発依存は `package-lock.json` を参照。
